Implemented a new QC process that reads a generate artifact, computes label-wise histograms and stats, and runs taxonomy-driven rule checks, writing `metrics/qc.json` plus `metrics/label_summary.csv` with fixed bin definitions from config for comparability. The core logic lives in `src/synthlab/processes/qc.py` (input resolution, table loading, hist/stats, rule checks), `conf/wafer_particles/qc/default.yaml` defines bins/quantiles/rule thresholds, and `conf/process/qc.yaml` wires those defaults into the qc process; `src/synthlab/processes/__init__.py` registers the new process.

**Verification**
- `python -m synthlab.cli.main process=generate seed=1 run_name=qc_demo`
- `python -m synthlab.cli.main process=qc seed=1 run_name=qc_demo_qc wafer_particles.qc.input.run_name=qc_demo`
