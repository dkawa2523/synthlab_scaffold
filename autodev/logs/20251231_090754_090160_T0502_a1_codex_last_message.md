Wired in numpy-backed param‑space sampling/validation and centralized parameter sampling, then expanded doctor to gate on invalid configs with schema checks, plus updated pattern/labeling configs and added targeted tests. This keeps parameter sampling deterministic via injected RNGs and surfaces precise error paths in doctor.

More context:
- `src/synthlab/domains/wafer_particles/param_space.py` defines the sampling/validation API for all supported dists and legacy range specs.
- `src/synthlab/processes/generate.py`, `src/synthlab/processes/calibrate_search.py`, and `src/synthlab/domains/wafer_particles/generators/patterns/composite.py` now use the shared param_space sampler for config‑driven params.
- `src/synthlab/processes/doctor.py` validates pattern params, n_particles specs, size_model constraints, optional pattern gating, and schema_version mismatches, and raises on error after writing `meta/doctor.json`.
- Pattern configs and the labeling spec now carry `schema_version`, and doctor defaults include patterns/size_models/labeling with `allow_optional_patterns` off.
