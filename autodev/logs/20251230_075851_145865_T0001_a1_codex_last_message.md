Added a minimal CLI entrypoint and dispatcher that resolve Hydra-style overrides into a config, write the artifact contract (config/meta/logs/README), and route to a registered process; implemented `doctor` plus a wafer_particles domain skeleton to match the architecture and process catalog.

**Details**
- `src/synthlab/cli/main.py` parses `key=value` overrides, fills defaults (seed/run_name), normalizes `process.name`, and dispatches to the framework.
- `src/synthlab/framework/artifacts.py` writes `config/resolved.yaml`, `config/overrides.txt`, `meta/meta.json`, `logs/console.log`, and computes `config_hash` per docs/04.
- `src/synthlab/processes/doctor.py` emits `meta/doctor.json` with basic environment info and logs progress.
- `src/synthlab/domains/wafer_particles/` adds the empty domain skeleton required by docs/01.

**Tests**
