# Patterns (C / K / O)

本ドメインでは、wafer上の粒子分布を表す **ルールベースパターン**を多数実装しています。

- C: core（主要パターン）
- K: keep（重ね合わせでは表現しにくいので別ラベルで保持）
- O: optional（規則パターン。必要な場合のみ）

---

## 1. パターン設計の考え方

### 1.1 「重ね合わせで十分」 vs 「別ラベルが必要」
**マスク重ね合わせ**で表現できても、半導体製造では原因が異なることがあります。
運用上は「見た目」だけでなく「原因の違い」を反映するため、以下のようなパターンは別ラベルで保持します。

- Edge_Arc（エッジ沿いの円弧）
- SemiRing_Segment（半リング片）
- Donut_Hollow（ドーナツ：中心空洞）

### 1.2 param_space を前提にする
各パターンは固定形状ではなく、以下の変動を **分布指定**で振れる設計にします。

- 粒子数（10–200 など）
- 位置（角度/半径）
- 幅（線幅、リング幅、扇形幅）
- 長さ（スクラッチ長）
- 密度（クラスタσ）
- 方向性（θ0、回転）

## 2. パターン一覧（要約）

> 実装のキー名は `conf/wafer_particles/patterns/` と pattern実装を真実として合わせてください。
> ここではラベル概念と、振るべきパラメータをまとめます。

### 2.1 Core（C01–C15）

| ID | 概要 | 振るべきパラメータ例 | 典型シナリオ |
|---|---|---|---|
| C01 Uniform | 全域ランダム | 粒子数、密度 | 背景ノイズ |
| C02 EdgeBiased | エッジ寄り | bias強度、半径分布 | edge起因 |
| C03 Ring | リング状 | r0、width | 環状堆積 |
| C04 Sector_Edge | エッジ扇形 | θ0、Δθ、r帯 | 局所汚染（端） |
| C05 Sector_Internal | 内部扇形 | θ0、Δθ、r帯 | 局所汚染（内部） |
| C06 RadialLines | 放射筋 | 本数、線幅、r範囲 | 流れ/帯電 |
| C07 StraightLine | 直線スクラッチ | 長さ(10–100mm)、幅(5–10mm)、角度 | 接触/搬送 |
| C08 CurvedScratch | 曲線スクラッチ | 曲率、span、幅 | 擦れ/接触 |
| C09 Spiral | 渦巻き | 角度伸長、幅 | 回転/流れ |
| C10 Hotspot_Iso | 等方クラスタ | 中心、σ | 局所堆積 |
| C11 Hotspot_Elliptic | 楕円クラスタ | σx/σy、角度 | 方向性あり |
| C12 Crescent_Edge | 三日月（端） | r帯、thickness、Δθ | 端部遮蔽/堆積 |
| C13 Crescent_Internal | 三日月（内） | r帯、thickness、Δθ | 内部遮蔽/堆積 |
| C14 EdgeSource_Spray | エッジ起点放射 | θ0、減衰、spread | focus ring等 |
| C15 EdgeSource_Bursty | エッジ起点塊+放射 | burst size、spread | 発生源局在 |

### 2.2 Keep（K01–K04）

| ID | 概要 | 別ラベルで保持する理由 |
|---|---|---|
| K01 Donut_Hollow | 中心空洞のドーナツ | リング＋中心マスクでは原因が異なるケースがある |
| K02 SemiRing_Segment | 半リング片 | セクタより「弧」形状が本質 |
| K03 Edge_Arc | エッジ沿いの円弧 | エッジ沿いの長い弧は別起因が多い |
| K04 Scratch_Periodic | 周期スクラッチ | 周期性が診断情報（振動/搬送系） |

### 2.3 Optional（O01–O02）

| ID | 概要 | 使いどころ |
|---|---|---|
| O01 ReticleRepeat | 格子状繰り返し | ステッパ/レチクル由来、周期性が要因分類に必要なら |
| O02 Checkerboard | 2D周期 | 計測アーティファクト、規則混入の検知 |

## 3. パラメータ設計ガイド

### 3.1 共通パラメータ（推奨）
| パラメータ | 意味 | 推奨 |
|---|---|---|
| `n_particles` | 粒子数 | 10–200（用途により増減） |
| `theta0` | 主方向 | `[0, 2π)`で一様 |
| `width_mm` / `width_norm` | 幅 | 物理妥当なレンジで一様 |
| `length_mm` | 長さ | 10–100mm（スクラッチ） |

### 3.2 被りを避けるための設計ヒント
- 「直線 vs 曲線」は別ラベル（C07 vs C08）
- 「等方クラスタ vs 楕円クラスタ」は別ラベル（C10 vs C11）
- 「エッジ接触形状 vs 内部形状」は別ラベル（C12 vs C13、C04 vs C05）
- 「放射状スプレー vs 放射＋塊」は別ラベル（C14 vs C15）
