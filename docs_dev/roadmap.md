# Roadmap（今後の拡張計画）

本フレームワークは「点群×粒径」ドメインの基盤として、将来の拡張を見越しています。
ここでは、優先度と目的を整理します。

---

## 1. 優先度の考え方

| 優先度 | 意味 |
|---|---|
| P0 | 運用で必要（破綻を防ぐ、配布できる） |
| P1 | 価値大（精度/解析力が上がる） |
| P2 | 中長期（拡張だが今すぐ必須ではない） |

---

## 2. 直近（P0候補）

| 項目 | 概要 | 価値 |
|---|---|---|
| 生成スケール/品質の強化 | 大規模生成でも破綻しない | 運用の安定化 |
| export強化（配布） | HF Dataset / TFRecord等 | MLパイプライン接続 |
| distance指標の拡充 | 合成vs実測の距離 | 新パターン必要性判定 |

---

## 3. 価値大（P1）

| 項目 | 概要 | 価値 |
|---|---|---|
| 少数実測でのキャリブレーション | 分布パラメータ推定・補正 | 現実一致の向上 |
| パターン自動提案 | 実測に足りないパターンを検出 | 開発効率 |
| 異常注入ベンチ拡充 | sizeだけでなく形状異常も | 異常検出評価 |

---

## 4. 中長期（P2）

| 項目 | 概要 |
|---|---|
| 画像/動画ドメイン | ヒートマップや顕微鏡像合成 |
| 深層生成（diffusion等） | ルール→学習生成へ |
| prompt→pattern | 自然言語からプラグイン生成（半自動） |
| ClearML等のMLOps連携 | 実験管理・共有 |

---

## 5. リスクと対策

| リスク | 具体例 | 対策 |
|---|---|---|
| ラベル粒度が増えすぎ | 100+クラスで運用破綻 | macro/specで集約、similarity_groups |
| 互換性破壊 | カラム名変更 | v2で切る、移行ガイド |
| 設定の複雑化 | YAMLが読めない | profiles/benchmarksでプリセット化 |
